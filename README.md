# Roguelike Top-Down Shooter

A dark atmospheric roguelike top-down shooter built with **Unity** and **C#**.

---

## 🎮 About The Game

This is a solo-developed project created as part of a game development dream.

The game combines classic top-down shooter mechanics with roguelike elements and a dynamic darkness system to create tension and strategic gameplay.

The player explores a dark map using a flashlight. Only the illuminated area is visible — enemies outside the light radius remain hidden, increasing difficulty and immersion.

---

## 🔦 Core Features

- 🔫 Top-down shooter mechanics  
- 🌑 Dynamic darkness system  
- 🔦 Flashlight-based visibility  
- 👾 Enemies visible only inside the light radius  
- 🎲 Roguelike elements  
- 💀 Fast-paced combat  

---

## 🛠️ Built With

- Unity Engine  
- C#  
- Unity 2D Lighting & Shadow System  

---

## 🎯 Gameplay Concept

- Survive enemy encounters
- Buy new weapons and upgrades
- Slay the final boss!
- *Beware the darkness...*
